## Eggsplosion
### A minecraft plugin that lets specific players in creative mode use eggs as tnt

#### heres the config
``` yml
#config file for Eggsplosion.

#"true" or "false"
enable-explosion: true

#amount of power the egg should have. e.g. 4 for regular tnt size
#to see different power levels, use https://www.minecraftmaps.com/tools/explosion-calculator
explosion-power: 1

#uuids of players who can explode eggs on use. e.g. "01234567-89ab-cdef-ghij-klmnopqrstuv"
# to see players uuids, use https://namemc.com/ and search your, or another players, username.
allowed-uuids:
  - ""
  - ""
```
